# AnzuU2U

Brief:
A Futaba Anzu themed USB2.0 to UART convertor with integrated CH340N chip and two LED indicators which twinkles when the device communicates with another one. With USB 2.0 defferential signal getting into CH340N,the convertor core will convert the signal to serial port signal.

Key Reminder:
1. Crossing Connection:
TX(dev_A) must be connected with RX(dev_B) and RX(dev_A) must be connected with TX(dev_B) otherwise signal cannot be received.

3. Data Format:
Serial digital signals are high voltage when available. Beginning bit pulled low, then it started transferring data bit, check bit and halt bit respectively in order of bit sequence.

Solution Features:
1.Simplified Peripheral

2.Macro Package

3.Full speed compatibility

4.Wide Voltage

5.High Baud rate

6.Plug and Play
